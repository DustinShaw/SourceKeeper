# 源管家 · 需特殊上网（代理/科学上网）域名库（可编辑本地文件）
# ==========================================================
# 用途：源测速时若命中本库中的域名，或域名 DNS 解析失败 / 连接超时，
#       则标记该源为「需特殊上网」——提醒你不是源坏了，而是直连走不通。
#
# 语法：每行一个域名（或域名后缀），以 # 开头为注释，空行忽略。
#   · 子域名自动匹配：写 `google.com` 可命中 `www.google.com` / `apis.google.com`；
#   · 支持通配符前缀 `*.example.com`（等价于后缀匹配）；
#   · 大小写不敏感。
#
# 修改后点「源管家 → 管理站点 → 重新载入词库」即生效。
